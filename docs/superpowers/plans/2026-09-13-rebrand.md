# Rebrand Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Restyle the public Keepsite Media site to match the new logo: its three stripe colors, black on white, Arial and Georgia italic and Montserrat, and its stripe-and-rule ornament.

**Architecture:** The site is token-driven, so most of the change is in `src/styles/global.css` and flows through every page. Around it: the font packages swap, a Logo component replaces the text brand in header and footer, the favicon and share image are rebuilt from the logo, the drifting background shapes are deleted, and a handful of page styles that reached past the tokens are edited by hand. The build verifier gains checks so the old brand cannot come back.

**Tech Stack:** Astro 5 static, Netlify, `@fontsource/arimo`, `@fontsource/gelasio`, `@fontsource/montserrat`, sharp for images, `scripts/verify.mjs` as the post-build test, puppeteer for screenshots.

**Spec:** `docs/superpowers/specs/2026-09-13-rebrand-design.md`

## Global Constraints

- Public pages only. `/office/` keeps building on the new tokens but is not restyled.
- Colors, exactly: bg `#FFFFFF`, surface-alt `#F4F1EC`, ink `#111111`, muted `#5A5A5A`, brand (rust) `#B8512C`, brand-deep `#8F3E22`, slate `#628997`, mustard `#DFAA3F`, mustard-deep `#C9962F`, copper `#D1884B`, border `#E3DED6`.
- Slate, mustard, and copper never carry text and never sit under white text. Rust is the only colored text.
- Font stacks, exactly: sans `Arial, 'Arimo', 'Liberation Sans', Helvetica, sans-serif`; serif `Georgia, 'Gelasio', 'Times New Roman', serif`; label `'Montserrat', Arial, 'Arimo', sans-serif`.
- Italic is allowed only through the `.serif` class. Nothing else sets `font-style: italic`.
- No third-party font origin. Fonts come from `node_modules` through fontsource and are bundled by Astro.
- Every text color pair is at least 4.5:1.
- Commit messages: imperative subject under 50 characters, body only when the reason is not obvious. Every commit ends with the two attribution lines given in the session.
- The dev server on `/mnt/c` does not see file changes under WSL2. Build (`npm run build`) and serve `dist/` rather than trusting `astro dev`.

```js
// Montserrat is the one face every visitor downloads (Arial and Georgia are
// system faces; Arimo and Gelasio only load where those are missing). The
// preload sits in the HTML and the @font-face in an externalized stylesheet,
// so the hash has to agree across both files.
check('the preload and the stylesheet request the same file', () => {
  const LABEL = /\/_astro\/montserrat-latin-700-normal\.[A-Za-z0-9_-]+\.woff2/g;
  for (const p of PAGES) {
    const html = read(p);
    const sheets = [...html.matchAll(/<link[^>]*rel="stylesheet"[^>]*href="(\/_astro\/[^"]+\.css)"/g)].map((m) =>
      read(m[1].replace(/^\//, ''))
    );
    if (!sheets.length) throw new Error(p + ' links no stylesheet');
    const inHtml = new Set(html.match(LABEL) || []);
    const inCss = new Set(sheets.flatMap((c) => c.match(LABEL) || []));
    if (inHtml.size !== 1) throw new Error(`${p} preloads ${inHtml.size} label assets`);
    if (inCss.size !== 1) throw new Error(`${p} stylesheets declare ${inCss.size} label assets`);
    const [preloaded] = [...inHtml];
    const [declared] = [...inCss];
    if (preloaded !== declared) throw new Error(`${p} preloads ${preloaded} but loads ${declared}`);
    for (const s of [html, ...sheets]) {
      if (s.includes('fonts.googleapis.com')) throw new Error(p + ' uses a third-party font origin');
    }
  }
});
check('the retired faces are gone from every stylesheet', () => {
  for (const p of PAGES) {
    const html = read(p);
    const sheets = [...html.matchAll(/<link[^>]*rel="stylesheet"[^>]*href="(\/_astro\/[^"]+\.css)"/g)].map((m) =>

    );
    for (const s of sheets) {
      for (const face of ['Instrument Sans', 'Newsreader']) {
        if (s.includes(face)) throw new Error(`${p} still declares ${face}`);
      }
    }
  }
});
```

```python
def lum(h):
    r, g, b = [int(h[i:i+2], 16) / 255 for i in (1, 3, 5)]
    f = lambda c: c / 12.92 if c <= 0.03928 else ((c + 0.055) / 1.055) ** 2.4
    return 0.2126 * f(r) + 0.7152 * f(g) + 0.0722 * f(b)

def cr(a, b):
    la, lb = lum(a), lum(b)
    hi, lo = max(la, lb), min(la, lb)
    return (hi + 0.05) / (lo + 0.05)

pairs = [
    ('ink on white', '#111111', '#FFFFFF'),
    ('ink on surface-alt', '#111111', '#F4F1EC'),
    ('muted on white', '#5A5A5A', '#FFFFFF'),

    ('rust-deep on white', '#8F3E22', '#FFFFFF'),

]
bad = [(n, a, b, cr(a, b)) for n, a, b in pairs if cr(a, b) < 4.5]
```
